# Power BI Dashboard

This folder contains the Power BI report for Ecommerce Sales and Customer Analytics.

## Report File

`ecommerce_dashboard.pbix`

The PBIX file is created and saved manually using Power BI Desktop.

## Report Pages

### Page 1: Executive Overview

Provides a high-level view of sales and business performance.

Visuals:
- Gross Sales
- Net Sales After Returns
- Retained Profit
- Delivered Orders
- Return Rate
- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Top Products

### Page 2: Product & Returns

Analyzes product performance and return activity.

Visuals:
- Returned Item Lines
- Return Rate
- Units Sold
- Products with Most Returns
- Returns by Reason
- Product-Level Return Details

### Page 3: Customer Analytics

Analyzes customer behavior and customer segments.

Visuals:
- Customer Count
- Net Sales
- Average Order Value
- Retained Profit
- Sales by Customer Segment
- Top Customers

## Data Source

The report uses CSV exports generated by:

`src/analytics/export_powerbi_data.py`

The export directory is:

`data/processed/powerbi_output/`

## Refresh Instructions

1. Run the data pipeline successfully.
2. Confirm the Power BI CSV exports exist.
3. Open the PBIX file in Power BI Desktop.
4. Select Home → Refresh.
5. Verify report filters and KPI values.
6. Save the report.

## Important

The CSV exporter does not modify the PBIX file automatically.

The report must be refreshed and saved through Power BI Desktop unless a separate Power BI deployment and refresh workflow is configured.
