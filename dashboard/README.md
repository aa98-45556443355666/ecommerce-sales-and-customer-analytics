# E-Commerce Power BI Dashboard

## Overview

The dashboard provides a reporting layer for the PostgreSQL
e-commerce star-schema warehouse.

## Data Sources

The report uses CSV exports generated by:

`src/analytics/export_powerbi_data.py`

The main data model contains:

- `dim_customer`
- `dim_product`
- `dim_date`
- `dim_region`
- `powerbi_sales_fact`

Additional reporting datasets are available for KPIs, product
performance, customer segments, regional analysis, and returns.

## Data Model

The warehouse uses a star schema. Dimension tables connect to
the sales fact table using surrogate keys.

## Main Dashboard Pages

1. Executive Overview
2. Product & Returns
3. Customer Analytics

## Refresh Workflow

1. Run the e-commerce pipeline.
2. Create or update the Power BI SQL views.
3. Export the datasets.
4. Refresh the imported data in Power BI Desktop.
