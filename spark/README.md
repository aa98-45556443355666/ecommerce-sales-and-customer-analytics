# PySpark Analytics

This module processes denormalized sales data extracted from the
PostgreSQL star-schema warehouse.

## Input

`data/processed/spark_input/sales_data.csv`

The input is generated by:

`src/spark/export_spark_input.py`

## Technology

- Python
- Apache Spark / PySpark
- PostgreSQL
- Spark DataFrames
- Spark SQL aggregations

## Reports

The pipeline creates:

- Monthly sales performance
- Category performance
- Product performance
- Regional performance
- Customer performance
- RFM-style customer segments
- Return reason analysis
- Weekday/weekend performance

## Run

From the repository root:

```powershell
python src/spark/export_spark_input.py
python spark/sales_aggregation.py
